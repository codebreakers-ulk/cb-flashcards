# Flashcard Vault

A client-side personal flashcard application inspired by Anki for revising programming concepts and tech terms.

Built with vanilla HTML, CSS, and JavaScript. Data persists directly in the browser using localStorage.

---

## Getting Started Locally

No installation or server setup required.

1. Fork this repository on GitHub.

2. Clone your fork:
   ```bash
   git clone https://github.com/<your-username>/cb-flashcards.git
   cd cb-flashcards
   ```

3. Open index.html in your browser:
   Double-click index.html or open it with your preferred browser.
